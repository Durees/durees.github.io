# 起因
因为在B站看到UP推荐《SPEC》，说是很好看的日剧，看简介和封面确实吸引我，看到有介绍前传《继续》，说是不影响看《SPEC》。但是本着看就要看全部的松鼠党心态，就要从前传看起来。

# 《继续》
当我看完全部tv、sp和movie，确实有一种怅然若失的感觉。一般情况我不喜欢看完全部的剧情，无论是小说，还是电影。打完游戏，看着制作人单会有一种奇怪的感受——这个故事完结了，让我很不舒服。

回到继续本身，故事开局是常见的警探剧，一个天才美少女，一个没头脑的硬汉（其实是普通人智商，只是和女主比较）。故事也是在推进这个时代常见的问题，也给出了一些思考，我认为是很偏现实的剧，带了一些艺术化处理。随着剧情，逐渐进入朝仓篇（我其实特别讨厌这种划分方式，好像剧情真的就会按照篇章划分。大概吧）故事倾向于开始有一些意识流的奇幻能力，但是也还可以用现实和科技解释。*侦探剧的重点不就是给出一样的线索，看侦探和读者谁快* 朝仓可以随意**变形**/化身/传播的特性还是bug。我可以归纳为一些特殊事件作为亮点，但是内核还是正常人/普通人的犯罪和警察的斗智斗勇，这是人类的范围。

到了SP一开始就是一个特别玄幻的开端，诅咒、幽灵什么的都上来了，确实吸引人，看起来是一个好的故事。最后也解释清楚是人类范畴的故事。朝仓就像是一个幽灵最后出现，带来了致命的阴影。

Movie的部分就是为了画上一个句号，给了所有演员集体谢幕，各种角色都有了结尾。最后的红雾部分可以算得上相当的意识流，一种完全不知道是真实世界还是真的进入冥界。但我可以说我还是认真看完，也认可这个故事有了一个完整的结尾。

总的来说，我在这个部分中可以看到一些时代的气息和人与人之间的斗智斗勇，是人类和社会的共同作用的剧集。特殊能力还是噱头，调味剂，剧集是讨论特殊能力在犯罪中的可能性。

*继续让我成功喜欢中谷美纪，虽然她快和我妈一个年纪了。* 时代变迁，平成时代的剧还是有着一种昭和时代的遗产，以及泡沫经济的绚烂，有着让人怀念的真实感。这份真实是我现在看东西最大的动力，可能我现在也很迷茫吧，我需要一些真实的东西来锚定我的存在。

# 《SPEC》
我看完了tv和翔，便决定放弃看完全部。一种小孩子过家家的优质感，不知道为什么，虽然演员很努力，但是大家对特殊能力的接受能力就像是你今天没有吃午饭。平淡，这种超出日常的能力，就有一种荒诞，但是又荒诞不到搞笑漫画的地步。*我看银魂就不会考虑这种问题。*

考虑到时代，2010年左右，人们开始幻想和讨厌现实，日本失去的30年开始持续发力。观众确实喜欢一些可以逃避现实的间隙，过于真实，*我老公出轨，我要不要杀了他。然后开始构思各种方法？还是我要用我的特殊能力改变现实*前者是侦探剧，后者是机械降神。虽然两者都是肥皂剧，但是前者还是可以作为一个len去看一看，后者直接可以归纳为*浪费时间*，特殊能力对决有**jojo**，*海贼王*，珠玉在前。

然后我有了特殊能力，我要变成世界的王！一种中二气息开始弥漫，一/阳太看起来太小丑了，没有B格。时间系能力者居然不能保证自己的记忆。记忆塑造能力者作为tv的BOSS看起来格局真的不大，和口号中的世界掌控/改变世界的人。**真的不行。**

# 后记
我会安利《继续》，对于《SPEC》我实在看不下去。作为一个记录吧，比较相隔如此之久，看完一个完整作品。
